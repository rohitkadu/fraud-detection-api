What is this project?

                

                    Hey, I built this pipeline to tackle a classic machine learning headache: detecting fraud when the data is massively imbalanced. If an AI just guesses "Normal" on every transaction, it will be 99.8% accurate, but it completely fails to catch the bad guys. 
                

                

                    I deployed this as a FastAPI backend so you can test how different algorithms evaluate the exact same data in real-time.
                

            


            

                
About the Dataset

                

                    I used the Kaggle European Credit Card dataset. It contains 284,807 real transactions, but only 492 of them are actual frauds. 
                

                
    
                    
  • Privacy features (V1 to V28): To protect user privacy, the bank ran PCA (Principal Component Analysis) to scramble things like merchant name and location into raw numbers.
    • 
                    
  • Time & Amount: These are the only untouched columns. I scaled these using a `RobustScaler` before feeding them to the models because standard scalers get ruined by massive fraudulent dollar amounts.
    • 
                

            


            

                
The Three Models

                

                    

                        
1. XGBoost

                        
This is the heavy lifter. It builds trees sequentially to fix previous mistakes. I tweaked the class weights so that if it misses a fraud case, it gets penalized 577 times harder than normal.

                    

                    

                        
2. Random Forest

                        
A solid ensemble model that builds decision trees independently. Good accuracy, but usually a bit slower and slightly less precise than XGBoost here.

                    

                    

                        
3. Logistic Regression

                        
I threw this in as a baseline. It's super fast, but you'll notice in the metrics that its Precision is terrible—it flags way too many normal transactions as fraud.
